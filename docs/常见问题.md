# 批量重命名 · 常见问题

## 安装与运行

### 安装版和便携版有什么区别？

| | 安装版 | 便携版 ZIP |
|---|--------|------------|
| 安装 | 需运行安装程序 | 解压即用 |
| 卸载 | 控制面板卸载 | 删除文件夹即可 |
| 适用 | 长期使用 | U 盘、临时电脑 |

两者功能完全相同。

### 提示缺少 WebView2 怎么办？

本应用基于 Tauri，需要 **Microsoft Edge WebView2** 运行时。

- **Windows 11**：通常已自带，直接运行即可
- **Windows 10**：首次启动若提示缺失，请按提示安装 WebView2，或从 [微软官网](https://developer.microsoft.com/microsoft-edge/webview2/) 下载「常青引导程序」

### 便携版解压后无法启动？

1. 确认解压完整，不要只复制 `.exe` 而遗漏同目录文件
2. 路径不要含特殊字符，建议放在英文路径下测试
3. 检查是否被杀毒软件拦截，可添加信任
4. 安装 WebView2 后重试

### 窗口图标显示不对？

完全退出应用后重新打开。Windows 可能缓存旧图标，重启应用或注销系统后会更新。

## 使用相关

### 为什么改规则时列表不变化？

**查找替换、智能、插入、自动编号** 模式下，编辑规则时**不实时预览**，避免频繁刷新。执行重命名时才会按当前规则改名。工具栏会显示「N 个将变更」供参考。

**手动编辑** 模式会实时显示预览。

### 执行后文件列表会清空吗？

不会。成功后列表保留，状态显示「已更新」，便于核对。

### 重命名可以撤销吗？

可以。在「操作历史」中点击「撤销」，或使用 `Ctrl+Z`。撤销会将文件改回操作前的名称。

如果只撤销了一部分（例如某个文件正被占用），未成功的项目会保留在历史里，再点一次「撤销」即可重试；界面不会把它们误标为已撤销。

### 部分文件失败怎么办？

执行结果会提示成功数与失败数。若部分成功，可选择**回滚已成功的文件**。失败常见原因：

- 目标文件名已存在（从不覆盖已有文件）
- 批次内有两个文件指向同一个名称，或大小写不敏感重名
- 文件名含非法字符 `<>:"/\|?*`、Windows 保留设备名（CON、NUL 等）
- 文件被其他程序占用，或路径超出已选目录

### 正则怎么用？

在「查找替换」中勾选「正则匹配」。例如：

- 查找 `\d+` 替换为 `编号` — 将连续数字替换为文字
- 为防止界面卡死，过长或带嵌套量词、反向引用等高风险写法会被自动停用并给出提示
- 建议先小批量测试，再整批执行

### 智能模式 EXIF / ID3 不生效？

- **EXIF**：支持常见图片格式（如 JPG），无 EXIF 的图会跳过该变量
- **ID3**：当前仅支持 **MP3** 文件的 ID3 标签
- 变量无数据时，预览结果可能为空或保留原逻辑，请先试几个样本文件

### 批量粘贴行数对不上？

- 粘贴行 **多于** 文件数：只应用前几行，其余提示
- 粘贴行 **少于** 文件数：已粘贴的会更新，其余保持原名

### 勾选「递归子目录」会怎样？

添加文件夹时，会包含所有子文件夹中的文件。文件较多时请耐心等待加载完成。

## 隐私与安全

### 会上传我的文件吗？

**不会。** 所有操作在本地完成，不联网、不上传、不收集文件名或路径。

### 配置保存在哪里？

模式、规则、主题、语言等偏好保存在本机浏览器本地存储（`localStorage`），仅用于下次打开时恢复，不上传。

## 快捷键一览

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+O` | 添加文件 |
| `Ctrl+Shift+O` | 添加文件夹 |
| `Ctrl+Shift+L` | 清空列表 |
| `Ctrl+Enter` | 执行重命名 |
| `Ctrl+Z` | 撤销最近操作 |
| `Ctrl+V` | 手动模式批量粘贴（列表区） |
