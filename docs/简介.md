# 批量重命名 · 简介

**批量重命名** 是 [墨点 inkdot](https://inkdot.cn) 出品的开源桌面工具，用于在本地批量修改文件名，无需联网、无需注册。

## 适用场景

- 整理照片、截图、下载文件，统一命名规则
- 批量替换文件名中的关键词、日期、序号
- 根据 EXIF / ID3 元数据生成新文件名
- 从 Excel 复制一列名称，批量粘贴到文件列表

## 核心特点

| 特点 | 说明 |
|------|------|
| **五种模式** | 查找替换、智能重命名、插入内容、自动编号、手动编辑 |
| **本地运行** | 所有预览与重命名在电脑本地完成，文件不上传 |
| **可撤销** | 支持操作历史与一键回滚 |
| **中英界面** | 重命名相关界面支持中文 / English |
| **深色主题** | 支持浅色 / 深色切换 |

## 产品原则

- **开源** — MIT 许可，源码公开，可自由使用与分发
- **离线** — 断网可用
- **安全** — 不收集、不上传用户文件信息
- **方便** — 添加文件 → 设规则 → 执行
- **绿色** — 无广告、无捆绑、关闭即退出

详见 [PRINCIPLES.md](../PRINCIPLES.md)。

## 系统要求

- **Windows 10 / 11**（64 位），已安装 Microsoft Edge WebView2（Win11 通常自带）
- **macOS 12+**（Apple Silicon，提供 `.dmg` 与 `.app.zip`）

## 获取方式

| 类型 | 说明 |
|------|------|
| **安装包** | `BatchRename_0.1.0_x64-setup.exe`，双击安装 |
| **便携版 ZIP** | 解压即用，无需安装，见 `release/` 目录 |
| **macOS** | `BatchRename-0.1.0-aarch64.dmg` 或 `.app.zip` |

## 安全边界

- 新文件名只能是文件名，不能带路径；源与目标必须位于同一已选目录内
- 目标已存在、批次内重名时跳过，绝不覆盖文件
- 交换与链式改名通过临时名分步完成；失败项自动放回原名
- 单批上限 5000 个文件，目录遍历深度上限 32 层，不跟随符号链接
