# 批量重命名 · 使用教程

## 快速上手（3 步）

1. **添加文件** — 点击「添加文件」或「添加文件夹」，也可拖拽到窗口
2. **选择模式并设置规则** — 在左侧选择重命名方式，在上方填写条件
3. **执行重命名** — 点击「执行重命名」，确认后整批一次性完成

> 所有模式都会实时预览目标文件名（预览在后台线程计算，不卡界面）；列表显示的就是执行时使用的结果，确认无误后再执行。

## 五种重命名模式

### 1. 查找替换

- **查找**：要匹配的文本；可勾选「正则匹配」「区分大小写」
- **替换成**：新文本；留空则删除匹配内容
- **替换文件扩展名**：勾选后也会替换扩展名部分
- 可添加多条规则，按顺序依次执行

**示例**：把所有 `IMG_` 替换为 `照片_`

### 2. 智能重命名

使用模板变量组合新文件名：

| 变量 | 含义 |
|------|------|
| `{stem}` | 不含扩展名的文件名 |
| `{name}` | 完整文件名 |
| `{ext}` | 扩展名（含点） |
| `{date}` | 当前日期 |
| `{filedate}` / `{filetime}` | 从原文件名解析的日期/时间 |
| `{exifdate}` / `{exiftime}` | 图片 EXIF 拍摄时间 |
| `{width}` / `{height}` / `{dimensions}` | 图片尺寸 |
| `{artist}` / `{title}` / `{album}` / `{id3year}` | MP3 ID3 标签 |

**示例模板**：`{date}_{stem}` → `2026-06-12_风景.jpg`

### 3. 插入内容

- **内容类型**：固定文本、序号、文件信息（修改时间、大小、EXIF、ID3 等）
- **插入位置**：开头、末尾、指定字符位置

### 4. 自动编号

- **序号前/后字符**：如 `照片_` 和 `_备份`
- **开始序号**、**固定位数**（补零）
- **序号类型**：阿拉伯数字、罗马数字、字母
- 序号按当前列表排序顺序分配

### 5. 手动编辑

- 在列表「预览文件名」列直接输入新名称
- **批量粘贴**：从 Excel 等复制一列，点击「批量粘贴」或 `Ctrl+V`（焦点不在输入框时）
- 粘贴行数与文件数不一致时会有提示

## 文件列表与状态

| 状态 | 含义 |
|------|------|
| 未变更 | 新名与原名相同 |
| 将变更 | 执行后会更名（工具栏统计用） |
| 冲突 | 目标文件名与同批其他文件冲突 |
| 非法 | 含非法字符或为空 |
| 重命名中 | 正在执行 |
| 已更新 | 已成功重命名 |

执行成功后列表会保留，可查看已改好的文件名。

## 工具栏

- **添加文件** `Ctrl+O`
- **添加文件夹** `Ctrl+Shift+O`（可勾选「递归子目录」）
- **清空** `Ctrl+Shift+L`
- **排序**：按名称或修改时间
- **执行重命名** `Ctrl+Enter`

---

## 操作历史与撤销

- 每次执行记入「操作历史」，包含本次真正改名成功的记录
- 点击「撤销」可回滚该次操作；`Ctrl+Z` 撤销最近一次未撤销的操作
- 若撤销只成功了一部分，未成功项仍留在历史里，再点一次「撤销」即可重试
- 交换文件名（A↔B）与链式改名也支持，内部用临时名分两步完成

## 主题与语言

- 侧栏应用名旁 **☀ / ☾** 切换浅色 / 深色
- 侧栏底部可切换 **中文 / English**（关于页、许可证页固定中文）

---

## 建议使用流程

1. 先用少量文件试跑，确认规则正确
2. 注意「冲突」「非法」状态，修正后再执行
3. 重要文件建议先备份或确认历史可撤销
4. 智能模式涉及 EXIF/ID3 时，仅对支持的格式生效（如 JPG、MP3）

更多问题见 [常见问题](./常见问题.md)。
